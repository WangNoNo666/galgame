## 故事

镇上已经七十一天没有下雨了。好阳是一只提了六年水的木桶，一天四趟，一桶水走四百二十步。
有一天他抬头，看见井边枣树上卡着一小团白——一朵太薄、连地面都湿不了的云，名字叫涨云初。

**云不能落地，落了就散；水桶不能上天，上了就掉。** 他们中间隔着一整片天。
